#   dipy=1.5.0  fsl-data_standard=2208.0  fsl-tbss=2111.1=hb6de94e_3

#   fsl-flirt=2111.2=hb6de94e_3  fsl-fnirt=2203.1=hb6de94e_0

#   libopenblas=0.3.30=pthreads_h94d23a6_0  libblas=3.9.0=32_h59b9bed_openblas
#   libcblas=3.9.0=32_he106b2a_openblas     liblapack=3.9.0=32_h7ac8fdf_openblas
#
# flirt, fnirt and avwutils are transitive deps of fsl-tbss, pinned here on
# purpose because all three reach the metric values: tbss_2_reg -> fsl_reg runs
# flirt then `fnirt --config=FA_2_FMRIB58_1mm` for the nonlinear warp to MNI,
# and avwutils supplies the fslmaths/fslstats calls eight tbss_* scripts rely on.
# fsl-fnirt also ships that .cnf, so bumping it can change the registration
# *configuration* (warp resolution, regularisation), not just the binary.
#
# The BLAS/LAPACK set is pinned to the versions in the container image used for
# the publication. Newer libopenblas changes np.linalg.pinv in the free-water fit
# by a few bits; on the reference subject that seeded four 1-ULP voxels in the
# fitted FA maps, nudged the deformation field by well under a voxel, and still
# moved the skeleton intersection by 6 voxels and delta-PSMD by 8% -- because the
# skeleton comes from thresholding an interpolated binary mask, where boundary
# voxels sit exactly on the threshold. With these pins (and the committed
# FMRIB58_FA_2mm_crop.nii.gz) DELTA-SVD reproduces the container image used for
# the publication bit-for-bit: verified 2026-07-29 on the reference subject,
# 79/79 NIfTI intermediates identical.
#
# NOTE - these four lines are hand-maintained, deliberately departing from the
# "regenerate, don't hand-edit" rule in CONTRIBUTING.md. Regenerating re-solves
# against current channels and would silently restore a newer libopenblas,
# undoing that bit-continuity. The set is internally consistent by construction
# (libblas 3.9.0 requires libopenblas >=0.3.30,<0.3.31) and is verified by
# building the image. If you regenerate, re-apply these four URLs afterwards.
#
# After ANY regeneration, re-validate against a LONGITUDINAL subject; a
